# ทะเบียนผู้ป่วยงานบริการวิสัญญี

เว็บแอปเริ่มต้นสำหรับหน่วยงานวิสัญญี รองรับหน้าลงทะเบียน, รายการทะเบียน, สถิติ, Pass PACU และเข้าสู่ระบบด้วย Supabase

## 1. อัปโหลดไป GitHub

อัปโหลด `index.html`, `styles.css`, `app.js`, `config.js`, `schema.sql`, `README.md` ไปที่ root ของ repository `anesthesia-registry` แล้ว Commit changes

## 2. เปิดหน้าเว็บเพื่อพรีวิว (ยังไม่บันทึกข้อมูลจริง)

Repository > Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save

เว็บจะปรากฏที่ `https://<username>.github.io/anesthesia-registry/` หลัง GitHub Pages deploy สำเร็จ โหมดตัวอย่างตั้งใจปิดการบันทึกข้อมูล (ไม่เก็บข้อมูลผู้ป่วยไว้ใน browser)

## 3. ตั้งค่าฐานข้อมูล (ก่อนการทดสอบแบบเชื่อมต่อ)

1. สร้าง Supabase project ซึ่งได้รับอนุญาตให้เก็บข้อมูลประเภทนี้จากหน่วยงานแล้ว
2. ใน SQL Editor รันเนื้อหาของ `schema.sql`
3. Supabase > Authentication > Users สร้างบัญชีทดสอบด้วยอีเมล / รหัสผ่าน
4. คัดลอก UUID ของผู้ใช้และเพิ่มสมาชิกใน SQL Editor ด้วย:

   `insert into public.registry_members(user_id,role) values ('UUID-OF-USER','staff');`

5. Supabase > Project Settings > API คัดลอก Project URL และ **anon/publishable** key มาใส่ใน `config.js` แล้ว Commit
6. เปิดหน้าเว็บใหม่ ไปที่ "ตั้งค่า" แล้วเข้าสู่ระบบ เพื่อทดสอบด้วยข้อมูลสมมติเท่านั้น

**ห้ามนำ `service_role` key / secret API key / รหัสผ่านไปใส่ใน GitHub** ตัวอย่างนี้ไม่เปิดการสมัครสมาชิกเอง

## 4. ข้อจำกัดที่ต้องตรวจสอบก่อนใช้งานข้อมูลจริง

- รายการ Technique/Device ปัจจุบันเป็นค่าตัวอย่าง ต้องแทนด้วยรายการตามรูปแบบทะเบียนหน่วยงานที่ตรวจทานแล้ว
- รายงานใน/นอกเวลาราชการเป็นเกณฑ์ จ.–ศ. 08:00–16:00 และยังไม่ตัดวันหยุดนักขัตฤกษ์
- รุ่นนี้ยังไม่มี audit trail การแก้ไข/ลบ, ระบบอนุมัติ, นโยบายเก็บรักษา/ลบ, แผนสำรองและคืนข้อมูล, การเข้ารหัสระดับฟิลด์
- การ export CSV มีข้อมูลระบุตัวบุคคล ต้องจำกัดสิทธิ์และจัดเก็บอย่างปลอดภัย
- หน้ารายการอ่านข้อมูลสูงสุด 1,000 แถวต่อครั้ง ยังไม่มี pagination สำหรับข้อมูลระยะยาว
- ทุกบัญชีสมาชิกในรุ่นนี้มีสิทธิ์ดู/แก้ไข/ลบทุกเคสของหน่วยงาน: ต้องตรวจสอบและออกแบบสิทธิ์จริงก่อนใช้งาน
- ต้องผ่านกระบวนการประเมินความปลอดภัยและ PDPA/ข้อกำหนดโรงพยาบาลก่อนใช้กับผู้ป่วยจริง

โค้ดนี้เป็น **ต้นแบบใช้งานทดสอบ** ไม่ใช่ระบบ production-ready สำหรับข้อมูลสุขภาพอ่อนไหว
